# AI Spend Auditor

AI Spend Auditor is a web application that helps users analyze and optimize their AI subscription costs across platforms like ChatGPT, Claude, Copilot, Gemini, and Cursor.

## Features

- Dynamic AI tool and plan selection
- Pricing-aware audit engine
- Recommendation system based on:
  - team size
  - monthly spend
  - use-case
- Local storage persistence
- Dynamic audit result generation

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
